## Documentation

The user guide is published on [gomddoc.com](https://gomddoc.com/docs/getting-started) and embedded in the binary:
`gomddoc help` serves it, and `gomddoc doctor ./docs` checks a site for configuration and content problems.

## Bugs and feature requests

Open an issue on [GitHub](https://github.com/monolithiclab/gomddoc/issues). Please include the output of
`gomddoc --version`, your operating system and the smallest site that shows the problem.
