## Documentation

The guides are published on [millstream.dev](https://millstream.dev/docs/): a getting-started tutorial, the action
protocol and a production checklist for agent steps. `millstream help` prints the guide embedded in the binary.

## Contact

For early access, the commercial edition, a bug report or any other question, write to
[contact@monolithiclab.fr](mailto:contact@monolithiclab.fr?subject=Millstream%20support). For a bug, please include
the output of `millstream version`, your operating system and the pipeline file that shows the problem.
